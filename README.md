# Real Estate Appointment App

A web application for a real estate agency to manage property listings and appointment bookings.

## Features
- Property listing management
- Appointment booking system
- Admin view for managing properties and schedules

## Technologies Used
- HTML, CSS, JavaScript
- PHP
- MySQL
